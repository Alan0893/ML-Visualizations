# ML Visualizations

Consolidated machine learning visualizations and CS 506 coursework. Each folder is a standalone project originally in its own repository.

## Visualizations

| Project | Description |
|---|---|
| [KMeans-Visualization](./KMeans-Visualization) | Interactive KMeans clustering with various initialization methods |
| [LSA-Search-Engine](./LSA-Search-Engine) | Document search using Latent Semantic Analysis (LSA) |
| [Linear-Regression-Visualization](./Linear-Regression-Visualization) | Interactive demo of regression parameters and null relationships |
| [Confidence-Intervals](./Confidence-Intervals) | Hypothesis tests and confidence intervals via simulation |
| [Logistic-Regression](./Logistic-Regression) | Decision boundaries and parameter shifts with clustered data |
| [Neural-Networks-Visualization](./Neural-Networks-Visualization) | Neural network features, decision boundaries, and gradients |
